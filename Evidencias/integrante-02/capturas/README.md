# Capturas del integrante 02

Guarda aquí las capturas tomadas en Unity 6000.3.23f1 con el formato
`NN-descripcion.png`, donde `NN` es el número de la ficha.

Ejemplos: `01-cerca.png`, `01-horizonte.png`, `02-mar.png`, `05-modulo.png`.

- Resolución de la vista Game: 1920x1080.
- Enlaza cada captura desde la sección *Evidencia* de su ficha.
