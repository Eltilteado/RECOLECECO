# Prueba de contacto con el muelle

Acércate por frente y costado. Registra si la chalana atraviesa el muelle, rebota o alcanza el punto de atraque.

## Registro para completar

- Fecha
- Commit probado
- Versión de Unity y escena
- Pasos que seguiste
- Resultado que observaste
- Evidencia o archivos cambiados
